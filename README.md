# Hardware Trojan Vulnerability Analysis Project

## Project Goal
This project builds a machine learning pipeline to classify hardware Trojan vulnerability images into:
- `HighVulnerableClass`
- `MediumVulnerableClass`
- `LowVulnerableClass`

The fixed split in `split_data/` is the source of truth and is not modified.

## How To Run
### 1. Activate environment
```bash
source myenv/bin/activate
```

### 2. Run Stage 1 (data -> arrays)
```bash
python pipelines/split_data_pipeline.py --input-dir split_data --output-dir pipeline_output
```

### 3. Run Stage 2 (arrays -> training/evaluation)
```bash
python pipelines/train_from_arrays.py --arrays-dir pipeline_output/arrays --output-dir pipeline_output/training
```
